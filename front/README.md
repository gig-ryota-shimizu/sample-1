# ローカル環境の起動

1. docker コンテナ立ち上げ

```bash
# プロジェクトルートで
make up
```

2. nodejs コンテナに入る

```bash
make node
```

3. ローカルサーバー立ち上げ

```bash
# localhost:3000 で立ち上がる
npm run dev
```

# html ファイルについて

src 配下の html ファイルは ejs 記法が使えます。

拡張子は html ですが、ejs として認識されます。
